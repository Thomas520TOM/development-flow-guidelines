# AGENTS.md

This repository uses this file as the opencode discovery layer referenced by `loading-spec.md` and `README.md`.

Discovery order:

1. Start with [SKILL.md](SKILL.md) for the system entry point.
2. Use [platforms/opencode/SKILL.md](platforms/opencode/SKILL.md) for opencode-specific activation details.
3. Follow the module files under `01-` through `09-` and the system-wide docs for execution.

This file is intentionally lightweight. The authoritative rules live in the module documents and platform adapters.
